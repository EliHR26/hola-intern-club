# 🚀 Directorio Oficial del Intern Club

¡Bienvenidos al primer repositorio colaborativo del Intern Club!
Este repositorio sirve para practicar el flujo de trabajo de código abierto (Open Source) creando tu primer **Pull Request (PR)**.

## 🛠️ Tu Misión

Tu objetivo es agregar tu perfil al directorio de miembros del club. Para lograrlo sin romper el código de los demás, seguiremos el flujo de trabajo de "Fork & Pull Request".

### Paso a paso:

1. **Haz un Fork:** Ve a la parte superior derecha de esta página y dale clic al botón `Fork`. Esto creará una copia exacta de este repositorio en tu propia cuenta de GitHub.
2. **Clona TU repositorio:** Abre VS Code, presiona `Ctrl+Shift+P` (o `Cmd+Shift+P`), escribe `Git: Clone` y pega la URL de **tu copia** (la que está en tu perfil, no esta original).
3. **Crea tu archivo:** Dentro de la carpeta `miembros/`, crea un archivo nuevo con tu nombre de usuario de GitHub y la extensión `.md`. Ejemplo: `miembros/diego-lopez.md`.
4. **Llena tu perfil:** Copia la plantilla de abajo, pégala en tu archivo y llena tus datos.
5. **Stage, Commit y Push:**
   - Guarda tu archivo.
   - Ve a la pestaña de _Source Control_ en VS Code.
   - Dale al **+** para hacer _Stage_.
   - Escribe un mensaje de commit (ej. "Agrego perfil de Diego").
   - Dale al botón azul de **Sync Changes**.
6. **Abre el Pull Request:** Regresa a la página de tu repositorio en GitHub y dale clic al botón verde que dice `Compare & pull request`. ¡Manda la solicitud y espera a que sea aprobada!
